# Pearls Opticians

Official website for **Pearls Opticians** — professional eye care and quality eyewear in Harare, Zimbabwe.

**Production:** [https://pearlsopticians.co.zw](https://pearlsopticians.co.zw)

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Brand assets

Favicons, PWA icons and the Open Graph preview image are generated from the official Pearls Opticians logo:

```sh
npm run generate:brand
```

Source logo: `brand-source/pearls-opticians-logo.png`  
Outputs land in `public/` (favicon set, `apple-touch-icon.png`, `icons/`, `images/og-default.jpg`, `images/pearls-opticians-brand.png`, `site.webmanifest`).
